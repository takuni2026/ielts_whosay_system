# IELTS Speaking Practice (Mac)

Macの画面の指定範囲をOCRで読み取り、内容を確認してからOllamaの`qwen3.5:4b`で回答を作るローカルアプリです。「IELTS英語」モードでは約200語のC1レベル回答例、「日本語クイズ」モードでは正解と選択肢の理由を日本語で説明します。質問の撮影はボタンを押した時だけ行います。画像や質問を外部APIへ送信しません。

## ビルド

macOS 14以降、Xcode Command Line Tools、Ollamaが必要です。

```sh
./build-app.sh
open "outputs/IELTS Speaking Practice.app"
```

アプリの初回起動時に、Ollamaが動作し、`qwen3.5:4b`が利用できる必要があります。Ollamaのメニューバーアプリを起動するか、ターミナルで次を実行してください。

```sh
ollama serve
```

アプリは起動時にモデルをメモリへ読み込み、15分間保持します。これは最初の回答を速く表示するためです。

## 使い方

1. 「質問の範囲を指定」を押し、画面上の問題文をドラッグして囲みます。
2. 「次の質問を読む」を押します。指定範囲を一度だけ撮影し、Vision OCRで英語を読み取ります。
3. 認識結果を確認し、必要なら質問文を修正します。
4. 「OK・回答を生成」を押します。回答は生成された部分から順次表示されます。
5. 次の問題に進む時だけ「次の質問を読む」を押します。

画面上部の回答モードを切り替えるとOCR言語と回答形式も切り替わります。日本語クイズでは、選択肢の記号と正解理由、他の選択肢が誤りである理由を説明します。

## AppleScriptから質問を読み取る

一度アプリで範囲を保存した後なら、別のAppleScriptから次のURLを開くと、その時点で画面に表示されている問題を一度だけ読み取れます。

```applescript
do shell script "/usr/bin/open -g 'ieltspractice://read-question'"
```

`-g`はアプリを前面に出さずに呼び出すための指定です。読み取り後はアプリの質問欄を確認してから、手動で回答生成を承認します。`ieltspractice://generate`を呼べば現在の質問への生成も開始できます。

日本語クイズなら、範囲の保存後に次の1行で撮影・OCR・日本語の答えと解説の生成を開始できます。実行するたびに日本語クイズモードへ切り替わり、確認ボタンは不要です。

```applescript
do shell script "/usr/bin/open -g 'ieltspractice://japanese-quiz'"
```

このURL呼び出しだけでは、回答本文はAppleScriptへ戻りません。生成後の最初の一文を受け取りたい場合は、別のAppleScriptから次のようにヘルパーを実行します。`firstSentence`変数に結果が入り、エラー時はAppleScriptエラーになります。

```applescript
set firstSentence to do shell script "/usr/bin/osascript " & quoted form of "/Users/takahashiryuuta/Documents/Codex/2026-10-03/mac-ielts/scripts/japanese-quiz.applescript"
```

ヘルパーはリクエストID付きでアプリを呼び出し、回答完了まで待って最初の一文を返します。回答本文は引き続きアプリにも表示されます。アプリとの受け渡しにはローカルのApplication Support内の一時ファイルを使い、読み取り後に削除します。範囲未設定、画面収録の許可不足、Ollama停止などの場合は、エラーを呼び出し元へ返します。

画面収録にはChromeとは別に、このアプリ自身の許可が必要です。「システム設定 > プライバシーとセキュリティ > 画面とシステムオーディオ収録」で IELTS Speaking Practice を許可した後、アプリを完全終了して再起動してください。アプリのエラー表示から設定画面を開けます。範囲の選択と読み取りには同じディスプレイを使用します。

## iPhoneから操作

MacとiPhoneを同じWi-Fiに接続し、Macアプリで「iPhone操作を開始」を押します。QRコードを読み取ると、iPhoneのブラウザから質問範囲の指定、質問の読み取り、回答生成を操作できます。iPhoneの範囲選択では、画面画像を表示して指で問題文を囲みます。選択範囲はMacに保存され、次回起動後も再利用できます。電話側のページは約1.3秒ごとに回答などの状態を取得しますが、Mac画面の撮影はボタンを押した時だけです。QR画面の「閉じる」でメイン画面に戻れます。停止ボタンを押すとサーバーを閉じます。

LAN内の操作ページにはランダムなトークンを付けています。Wi-Fiの端末間通信が遮断されているネットワークでは接続できません。
